# 项目目标

## 总体目标

面向 AI for Guqin（古琴智能计算）开展研究，完成一篇以“从 ABC notation 自动生成古琴减字谱”为核心的论文，并以 WWW 为目标投稿会议。

系统不仅要保证音高映射准确，还应体现古琴演奏所讲究的“韵”，能够合理使用走手、和弦等技法，并保持左右手指法在乐句中的连贯性与可演奏性。

## 核心任务

给定一段 ABC notation，生成与之对应的结构化减字谱。生成结果需要同时满足：

- **音高准确**：调弦、弦位、徽位和按散音关系正确。
- **指法合理**：左右手指法符合古琴演奏习惯，避免局部可行但前后冲突。
- **韵味表达**：能够根据音乐上下文选择走手、和弦及吟猱绰注等技法。
- **整体连贯**：以乐句或段落为单位优化，而不是逐音独立映射。
- **结果可解释**：保留生成依据、中间决策和无法确定的候选方案，便于琴家校订。

## 拟采用的技术路线

1. 建立定制化 Agent 工具，包括调弦解释、音高—弦徽映射、指法合法性检查和谱面格式转换。
2. 设计多 Agent 协作流程，例如定调 Agent、音位 Agent、指法 Agent、技法/韵味 Agent 和审校 Agent。
3. 从已授权谱面中提取并清洗一批高质量的 ABC—减字谱配对数据，保留原始证据和人工修订记录。
4. 探索少样本学习或迭代式 Agent 优化，使系统能够利用少量专家样本持续改进。
5. 设计兼顾音高准确性、可演奏性、指法连贯性和古琴风格的评估指标，并在独立测试集上验证。
6. 开展充分、严谨且可复现的对比实验和消融实验，分析不同工具、Agent 分工、上下文范围及数据规模的贡献。

## 当前已完成

- 已建立从已登录“丝桐里”App 采集授权谱面结构化数据的初步流程，可生成 `raw_data.json` 和 `data.json`。
- 已实现简谱、歌词与减字谱的解析和对齐，并输出便于人工校对的 JSON 与 Markdown。
- 已在 `scripts/extract_jianpu_jianzi.py` 中加入 `--raw`、`--out-dir` 和 ABC notation 输出。
- 已实现正调 `1=F`、各弦半音偏移和整体八度偏移的解释。
- 已修正或改进撮、撞、十徽、徽外及复合符号闭合等若干减字谱解析问题。
- 已定位窗口切分前的完整 source event list，修复了窗口边界缺音和全局去重误删问题。

## 当前重点

1. 扩展并抽检配对数据，建立可审计的人工纠错机制和跨曲目完整性回归。
2. 明确 ABC—减字谱任务的输入、输出和约束表示，形成可运行的基线系统。
3. 将“音高正确”“可演奏”“指法连贯”和“有古琴韵味”转化为可计算指标与专家评价方案。
4. 在扩大数据规模前先用少量高质量样本验证研究假设，避免数据采集和逆向工作偏离论文主线。

## 阶段性完成标准

- 配对数据中的音符顺序、音高、歌词和减字谱对应关系可追溯、可人工核验。
- 基线系统能够把一段 ABC notation 转换为合法的候选减字谱，并报告无法唯一确定的位置。
- 评估方案同时包含客观规则、与参考谱的比较和古琴演奏者的主观评价。
- 实验可复现，数据来源、清洗规则、人工修订和系统版本均有记录。
