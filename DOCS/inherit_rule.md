**一句话说：**减字谱的“同前”是一套**局部状态继承**规则——未写出的左手位置、右手指法或音色，有时沿用前文，但不是“凡省略就把上一音全部照搬”。

## 一、最明确的两条“同前”规则

一个完整谱字通常包含：

> 左手按指＋徽位｜右手指法＋弦序

### 1. 省去上半部：承前一谱字的左手状态

若一个新谱字**没有写左手按指、徽位部分**，一般表示左手仍在前一谱字已经确定的位置上。

更准确地说：

* **徽位沿用前音；**
* 通常也连同原来的左手按指、按弦状态沿用；
* 但要以中间是否出现过“上、下、进、退”等移位动作为准。

通行的记谱法说明将其概括为：“略去上半部”，表示左手徽位与前一谱字相同。([中国百科全书][1])

例如可抽象为：

> 大指九徽勾四 →〔省略上半部〕挑四
> 展开：大指九徽勾四 → 大指九徽挑四

这里第二音只换右手指法，左手仍按原位。

---

### 2. 只有弦序、没有右手指法：承前右手指法

若谱字中只出现弦号，而没有重新写“挑、勾、抹、剔”等右手指法，则右手指法承前。

例如：

> 勾三 → 五
> 展开：勾三 → 勾五

资料通常将这一规则表述为：“仅有弦名而无右手指法”，表示右手指法与前一谱字相同。([中国百科全书][1])

因此，这两种省略可以看作**分字段继承**：

| 谱面省略        | 默认承前      |
| ----------- | --------- |
| 省去上半部       | 左手按指、当前徽位 |
| 只有弦号，没有右手符号 | 右手指法      |

## 二、“就”：明确表示沿用当前左手指位

“就”不是单纯的空白省略，而是一个专门的**指位复用符号**。

典型过程是：

1. 前一音已经注明左手按指和徽位；
2. 左手又经过“上、下、进、退”等动作移到新位置；
3. 接下来要在这个**移到后的当前位置**再弹一音；
4. 谱中写“就”，不再重复左手按指和徽位。

成公亮的解释是：前一音用某指上、下至某徽后，需要在此弦或另一弦弹奏时，用“就”而不必再写某指、某徽位，即“就在此处弹”。([广陵散社区][2])

所以：

> “就”继承的不是前一谱字最初写出的徽位，
> 而是左手经过全部位移动作后形成的**当前实际位置**。

可以表示成：

> 大九勾四 → 上七六 → 就挑四

其意义是：

> 大指九徽勾四弦，随后上至七徽六分；再就在七徽六分处挑四弦。

这是打谱或程序解析时非常重要的一点。

## 三、吟、猱、撞、绰、注等，承接前一个按音

很多左手韵指并不是一个重新完整标注的按弹音，而是对前一音余音的继续处理，例如：

* 吟、猱
* 撞、逗、往来
* 上、下、进、退、复
* 绰、注
* 掐起、带起、抓起等依附性动作

这些符号通常省略：

* 左手是哪一指；
* 在哪一弦；
* 原始徽位；
* 有时也没有新的右手弹弦动作。

它们默认作用于**前一个已经建立的按音状态**。成公亮对吟、猱的定义均以“弹出按音之后的余音……”开头；“上、下、进、退”等也以既有按弦位置为动作起点。([广陵散社区][2])

例如：

> 大七六勾四 → 吟

展开理解为：

> 大指按四弦七徽六分，右手勾弦；随后大指仍在该弦该音位作吟。

这里的“吟”并不是一个“缺了很多成分的新谱字”，而是一个**附着于前音的后续动作**。从语法角度看，可以理解为省略了“大指七徽六分四弦”这一完整指法短语。([PyPI][3])

## 四、散音也可以局部承前

连续散音中，后一个谱字可以省略重复的“散”字头。

有教学实例明确说明：

> “勾五”写在“散挑七”之后时，省略了“散”，全称应为“散勾五”。([广陵散社区][4])

即：

> 散挑七 → 勾五
> 实际读作：散挑七 → 散勾五

因此，“散”的继承规则可表述为：

> 前音已明确建立散音状态，紧接的谱字没有出现按指、徽位或泛音标志时，可以继续按散音解释。

但这个规则要比左右手字段继承更谨慎，因为不同谱本的省写程度并不一致。

### 散音继承通常在这些情况下终止

* 出现左手按指＋徽位；
* 出现“泛起”或明确泛音结构；
* 出现明确的新“散”字重新确认；
* 结构或语义表明已经进入按音。

因此不能简单规定：

> “一旦出现散，以后一直都是散，直到出现另一个音色符号。”

它通常只是**紧邻、局部的同前关系**。

## 五、泛音采用“作用域继承”

泛音有更清晰的段落性规则：

* **泛起**：以下进入泛音句或泛音段；
* **泛止**：泛音段结束。

所以在“泛起”与“泛止”之间，不必给每个音反复标一个完整的泛音类别；其中各谱字默认处于泛音状态。([广陵散社区][2])

这不是严格意义上的“继承上一个音”，而是：

> 继承一个仍然有效的“泛音模式”。

可写成状态机：

```text
普通状态
   │ 泛起
   ▼
泛音状态 ──连续处理各谱字──
   │ 泛止
   ▼
普通状态
```

## 六、按音不是段落继承，而是默认推断

“按音”与“泛音”的处理不同。

成公亮的说明指出：

> 按音弹法通常不在某一音或某一段落前另行注明。([广陵散社区][2])

也就是说，谱中见到：

* 左手按指；
* 徽位；
* 相应右手弹弦；

自然就判定为按音。

因此按音主要是**结构推断**，而不是：

> 前一音是按音，所以后一音没标音色也自动继承为按音。

后一音若省去上半部，确实可能继续使用前一按弦状态；但这是“左手状态同前”，不是一个独立的“按音段落标志”。

## 七、弦序通常不能对新弹音任意承前

这一点容易和“徽位同前”混淆。

对于一个由右手重新弹出的新音：

* 弦序通常要写明；
* 或由撮、历、滚拂等复合指法本身及其附注确定；
* 不能仅因上一音在四弦，就把所有缺弦号的新谱字一律解释为四弦。

但对于：

* 吟、猱、撞；
* 上、下、进、退；
* 掐起、带起等左手连续动作，

它们通常自然作用于当前正在按奏或余音尚存的那根弦，因此会**隐含继承当前弦**。

所以要区分：

| 情况          | 是否可承前弦序           |
| ----------- | ----------------- |
| 新的右手拨弦音     | 一般不能随意承前，通常应明确    |
| 左手对前音的续作    | 默认作用于当前弦          |
| “就”后重新拨弦    | 左手位置承前，但所弹弦仍看谱中字样 |
| 撮、历、滚拂等组合指法 | 依该指法的专门结构判断       |

## 八、一个适合读谱或程序解析的总规则

可以把减字谱理解成维护以下几个“当前状态”：

```text
当前音色：散／泛／按
当前弦序
当前右手指法
当前左手按指
当前左手位置
```

每遇一个谱字：

1. **写出的项目更新状态；**
2. **允许省略的项目沿用现有状态；**
3. 上、下、进、退会改变“当前左手位置”；
4. “就”在改变后的当前位置重新取音；
5. 吟、猱等只加工当前余音，不建立完整的新按弹状态；
6. 泛起、泛止控制泛音作用域；
7. 散音可紧邻承前，但遇到明确按音、泛音结构即应终止。

最危险的解析方式是：

> “谱字里没写什么，就把上一音的所有字段全部复制。”

正确方法是：

> **按字段、按动作类型、按音色作用域分别继承。**

## 规则速查

| 简写现象      | 完整理解         | 继承内容        |
| --------- | ------------ | ----------- |
| 谱字省上半部    | 左手仍在前音状态     | 按指、当前徽位     |
| 只有弦号      | 仍用前一右手手法     | 右手指法        |
| “就”       | 在左手当前到达的位置再弹 | 按指、移动后的徽位   |
| 吟、猱、撞等    | 对前一按音余音作韵    | 弦、按指、当前音位   |
| 散挑七后写“勾五” | 实为“散勾五”      | 散音状态        |
| 泛起……泛止    | 中间各音均作泛音     | 泛音模式        |
| 出现左手按指＋徽位 | 自然判为按音       | 不是继承，而是结构推断 |

**核心结论：减字谱确实具有类似“上下文省略”和“状态机”的机制，但不同字段的继承条件不同；其中最稳定的是左手位置同前、右手指法同前和“就”，散音同前则更依赖紧邻语境与具体谱本。**
