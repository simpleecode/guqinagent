**一句话概括：先看该调弦中目标弦的散音；“散音”就是空弦音，“七徽泛音/按音”比空弦高八度，“七徽六分按音”约比空弦高小七度，也就是比七徽音低一个大二度；勾、挑本身不改变音高。**

以下采用国际音高记法，**中央 C = C4**。以现代常用“标准音”计算时，正调五弦为 A2（其四徽泛音为 A4=440 Hz），七弦散音依次为：

> **C2—D2—F2—G2—A2—C3—D3**

不过古琴独奏时常只保持弦间相对关系，整张琴可以整体调高或调低，因此谱字首先表示的是**相对音位**，不必然对应固定的绝对频率。([atlasensemble.nl][1])

## 一、先拆解你举的三个减字

| 减字读法        | 决定音高的部分    | 音高关系                   |
| ----------- | ---------- | ---------------------- |
| **散勾三**     | 散音、三弦      | 三弦空弦音                  |
| **泛七挑五**    | 泛音、七徽、五弦   | 五弦空弦音的高八度              |
| **按七徽六分挑七** | 按音、七徽六分、七弦 | 七弦空弦上方约小七度，或七徽按音下方约大二度 |

“勾”“挑”只说明右手用什么指法、向什么方向出弦；同一根弦、同一音位，换成勾、挑、抹、剔等，**音高原则上不变，音色和力度会变**。

### 为什么七徽六分不是“七徽以上再升高”？

琴上的徽序从岳山一侧数向龙龈方向增加。七徽是弦长的二分之一；从七徽往八徽走，有效发音弦长变长，所以音高反而下降。现代徽分法把相邻两徽间分作十份，“七六”即七徽向八徽方向六分。([维基百科][2])

按理想弦长估算：

[
七徽六分\approx 0.56L,\qquad
f\approx \frac{1}{0.56}f_0=\frac{25}{14}f_0
]

约为散音上方 **1004 音分**，十分接近十二平均律的小七度 1000 音分。因此实际译谱时通常先换算成：

> **散音 + 小七度 = 七徽音 − 大二度**

但古琴按音受按弦张力、琴弦粗细、琴面弧度和律制影响，实际位置通常需要用耳朵微调；尤其古谱中同一个“七六”还可能承担大全音、小全音等不同律高。([国琴网][3])

# 二、不同常见调弦下的三个例子

下表按现代常见弦式及标准音高近似换算。各弦式名称在不同谱本、琴派中偶有异名或细微差别。([维基百科][4])

| 弦式            | 一至七弦散音                  | **散勾三** | **泛七挑五** | **按七六挑七** |
| ------------- | ----------------------- | ------: | -------: | --------: |
| **正调**        | C2 D2 F2 G2 A2 C3 D3    |  **F2** |   **A3** |    **C4** |
| **蕤宾调／紧五弦**   | C2 D2 F2 G2 B♭2 C3 D3   |  **F2** |  **B♭3** |    **C4** |
| **慢角调／慢三弦**   | C2 D2 E2 G2 A2 C3 D3    |  **E2** |   **A3** |    **C4** |
| **清商调／紧二五七弦** | C2 E♭2 F2 G2 B♭2 C3 E♭3 |  **F2** |  **B♭3** |   **D♭4** |
| **慢宫调／慢一三六弦** | B1 D2 E2 G2 A2 B2 D3    |  **E2** |   **A3** |    **C4** |
| **慢商调／慢二弦**   | C2 C2 F2 G2 A2 C3 D3    |  **F2** |   **A3** |    **C4** |
| **无射调／紧五慢一**  | B♭1 D2 F2 G2 B♭2 C3 D3  |  **F2** |  **B♭3** |    **C4** |
| **凄凉调／紧二五弦**  | C2 E♭2 F2 G2 B♭2 C3 D3  |  **F2** |  **B♭3** |    **C4** |

可以看出：

* **散勾三**只在调弦改变三弦时变化，例如慢角、慢宫调中由 F2 变为 E2。
* **泛七挑五**只随五弦变化；紧五弦后由 A3 变为 B♭3。
* **按七六挑七**只随七弦变化；清商调紧七弦，所以由 C4 变成 D♭4。

## 三、逐个计算示范

### 1. 正调：散勾三

正调三弦散音为 F2：

[
\text{散勾三}=F2
]

标准十二平均律下约为 **87.31 Hz**。

---

### 2. 正调：泛七挑五

正调五弦散音为 A2。七徽是二分弦长的泛音节点，得到第二分音，即高八度：

[
A2\times2=A3
]

所以：

[
\text{泛七挑五}=A3
]

约为 **220 Hz**。

---

### 3. 正调：按七徽六分挑七

正调七弦散音为 D3。

* 七徽按音是 D4；
* 七徽六分比七徽低约一个大二度；
* 所以得到约 C4。

[
D3+\text{小七度}\approx C4
]

因此：

[
\text{按七六挑七}\approx C4
]

实际按弦点应依听觉略作调整，不应机械地把调音器“C4 正中”当作所有琴曲、律制中的唯一答案。

---

### 4. 蕤宾调：泛七挑五

蕤宾调是在正调基础上**紧五弦**，五弦由 A2 升为 B♭2：

[
\text{泛七挑五}=B♭3
]

而三弦、七弦未改变，因此：

* 散勾三仍为 F2；
* 按七六挑七仍约为 C4。

---

### 5. 慢角调：散勾三

慢角调在正调基础上**慢三弦**，三弦由 F2 降为 E2：

[
\text{散勾三}=E2
]

五弦、七弦不变，因此：

* 泛七挑五仍为 A3；
* 按七六挑七仍约为 C4。

---

### 6. 清商调：按七六挑七

清商调紧二、五、七弦，七弦由 D3 升为 E♭3：

[
E♭3+\text{小七度}=D♭4
]

所以：

[
\text{按七六挑七}\approx D♭4
]

同时五弦为 B♭2，所以：

[
\text{泛七挑五}=B♭3
]

---

# 四、再举几个正调中的常见例子

| 减字／读法     | 计算          | 正调音高 |
| --------- | ----------- | ---: |
| **散挑六**   | 六弦空弦        |   C3 |
| **泛七挑六**  | C3 高八度      |   C4 |
| **按七挑六**  | C3 高八度      |   C4 |
| **按七六挑六** | C3 上方小七度    |  B♭3 |
| **泛五勾三**  | 三弦 F2 的第三分音 |   C4 |
| **泛四挑五**  | 五弦 A2 的第四分音 |   A4 |
| **散勾七**   | 七弦空弦        |   D3 |
| **泛七挑七**  | D3 高八度      |   D4 |
| **按七挑七**  | D3 高八度      |   D4 |
| **按七六挑七** | D4 下方大二度    |   C4 |

这里有一个很典型的“同音异色”组合：

* **泛五勾三 = C4**
* **泛七挑六 = C4**
* **按七挑六 = C4**
* **按七六挑七 ≈ C4**

它们音高接近或相同，但分别利用不同弦、不同泛音和按音位置，音色、余韵与走手可能完全不同。这正是减字谱不能只转换成五线谱或简谱，而要保留指法信息的原因。
