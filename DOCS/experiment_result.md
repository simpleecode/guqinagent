warning 构成：音高失配 37、泛音同弦余韵 29、低徽过紧 19、散音同弦再按 8+8、拇指低位 1。GLM-5.3 为远大于本地 9B 的闭源模型，本组数字回答的是"拥有相同工具与长尾技法知识时，强 prompt 基线能到什么水平"：音高接近上限（有音高候选工具兜底），但装饰音 F1（7.158%）低于两阶段 SFT（17.013%）和单阶段 SFT（20.929%），弦徽与音色 F1 也低于两种教师轨迹 SFT 系统。这表明参考动作一致性与音高正确性存在差异；跨模型比较不能单独证明轨迹蒸馏的因果作用。该组不加载任何本地权重，与 SFT 各组不是同模型配对消融，跨组比较只作论文六臂表的行间对照。

复跑：`bash baseline/gepa_guqin/scripts/run_react_handbook_full.sh`（断点续跑，rollout 后自动事件级评估）。

证据：`baseline/gepa_guqin/runs/react_handbook_full_test50/`（预测含逐轮轨迹、启动配置、评估摘要快照，已入库）；事件级明细在本地 `evaluation_results/react_handbook_full_test50/`。
