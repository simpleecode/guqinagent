\paragraph{Evaluation Metrics.}
Pitch correctness is measured against the input jianpu melody. The expert jianzipu annotation supplies reference actions for fingering and technique metrics. Let $\mathcal I$ contain events for which the auditor returns a determinate matched or mismatched prediction. Let $a_i=1$ if event $i$ matches the target within 50 cents under the supported matching rules, and $a_i=0$ otherwise. Let $\mathcal A_i$ contain the tone pairs aligned by the auditor, with absolute error $\delta_{ij}$ in cents for pair $j$. We report
\begin{equation}
\begin{aligned}
\mathrm{PitchAcc}_{50}
&=\frac{\sum_{i\in\mathcal I}a_i}{|\mathcal I|},\\
\mathrm{PitchMAE}
&=\frac{\sum_{i\in\mathcal I}\sum_{j\in\mathcal A_i}\delta_{ij}}
{\sum_{i\in\mathcal I}|\mathcal A_i|}.
\end{aligned}
\label{eq:pitch-metrics}
\end{equation}
Accuracy uses events as its denominator; MAE averages aligned tone pairs, and a compound event can contribute multiple pairs. Unresolved cases are excluded from pitch scoring and must be reported separately. We report each condition's evaluable event count and accuracy on their intersection, since generated notation affects which expressions the auditor resolves. The complete event inventory includes structural and continuation events and is not the pitch denominator.

String F1 measures event-level string assignment against available reference labels. Left-hand fingering, right-hand fingering, and tone type are scored similarly and reported in Appendix~\ref{sec:detailed-results}. Tone type distinguishes open, stopped, and harmonic notes. Ornament precision, recall, and F1 use event-level sets of parsed ornaments. These metrics measure agreement with one expert realization; alternative playable realizations can receive lower scores. The current results do not include a joint string--hui F1.

Technique distribution similarity summarizes the relative use of named performance techniques. Each technique is counted at most once per event, then counts are normalized over all technique incidences in the corpus. For predicted and reference distributions $p$ and $q$ over their joint technique vocabulary $\mathcal V$, we use
\begin{equation}
\mathrm{TechSim}(p,q)=1-\frac{1}{2}\sum_{t\in\mathcal V}|p(t)-q(t)|.
\label{eq:technique-similarity}
\end{equation}
The score lies in $[0,1]$, with higher values indicating closer distributions. This metric excludes notation-state markers such as harmonic-region boundaries. It does not evaluate event order, and identical distributions can assign techniques to different events; ornament F1 retains a local comparison. Tone-type distribution similarity uses the same formula over open, stopped, and harmonic notes and is reported in the appendix.

Final warnings are counted by replaying completed plans through the runtime, including when warnings were hidden during inference. The rule-violation rate is the fraction of the 1,031 work units with at least one final warning; the total warning count is also reported. Unresolvable expressions do not automatically become violations, and a warning-free plan is not certified as playable.

\paragraph{Models and Comparisons.}
The feedback comparison uses Qwen3.5-9B with the same project-trained two-stage LoRA weights in both conditions. The full system exposes warnings, diagnostic hints, and warning-triggered follow-up interactions. The diagnostic-feedback-off condition hides this feedback and disables its follow-up mechanism while retaining structural validation and pitch candidates. Its public user and tool messages were checked for diagnostic-feedback leakage.

The single-stage student uses a separately trained Qwen3.5-9B LoRA and generates final jianzipu through the same tools. It is allowed up to 16 rounds per attempt, while the two-stage pipeline allows eight rounds per stage attempt and up to three Guqinizer passes. The nominal ceilings of 16 versus eight plus eight rounds do not equate aggregate inference budgets when retries and additional passes occur. We therefore compare the resulting pipelines without attributing every difference solely to stage decomposition. Both are evaluated on the same scores using complete model-generated histories and the same scoring rules.

We also evaluated the original Qwen3.5-9B checkpoint without the project LoRA using the two-stage agent and the same tool definitions. All 59 attempted inputs matched the test-input hashes. The original-model run allowed 8,192 output tokens per request, eight rounds per stage attempt, up to three attempts, and up to three Guqinizer passes, with a context limit of 16,384 tokens. After a work unit failed, the evaluator skipped the remainder of that score, preserving the requirement that history contain model-generated predecessors. These settings match the current SFT evaluation entry point; archived SFT outputs span multiple runs, so this comparison does not establish that every historical execution setting was identical.

The commercial-model ReAct + Handbook baseline uses GLM-5.3 through its API with the production single-stage prompt and a fixed 73-entry technique handbook. It allows eight rounds and two attempts at temperature 0.25, uses the same tools and scoring pipeline, and produces protocol-valid outputs for all 1,031 units. A separate GLM API baseline with prompts optimized by GEPA on development data remains pending \cite{agrawal2026gepa}. These comparisons involve different model backends and do not isolate prompt optimization from model capability. GEPA's reflection model, API settings, optimization budget, and inference costs will be reported. Direct generation with the original Qwen checkpoint remains an optional additional comparison.

\subsection{Main Results}

\paragraph{Original-model completion and protocol failures.}
The original-model agent attempted 59 of 1,031 work units across the 48 scores. Eleven attempts produced protocol-valid outputs (18.64\% of attempted units), while 48 failed. The remaining 972 units were skipped because a predecessor failed. Valid-output coverage was therefore 11/1,031 (1.07\%); skipped units are excluded from the attempted-unit protocol-failure denominator. All three adapted conditions produced valid outputs for all 1,031 units. We do not report full-test musical metrics for the original model or compare its 11 successful units directly with the adapted model's complete-test scores.

Of the 48 failed units, 13 failed during Fingering and 35 during Guqinizer. Logs record output truncation in 45 failed units, at least one attempt reaching round eight in 26, and three consecutive pitch-candidate-query rounds in 31. These observations overlap and are not a mutually exclusive attribution of failures. They suggest that sustained tool interaction and termination behavior are substantial obstacles for the original model under the current protocol, alongside the musical decisions required by the task.

\paragraph{Technique distributions and the commercial-model baseline.}
Technique distribution similarity is 0.7618 for single-stage SFT, 0.7616 for two-stage feedback OFF, and 0.7301 for the two-stage full system. Thus, fewer runtime warnings do not imply closer aggregate technique usage. GLM-5.3 with ReAct + Handbook attains 99.760\% pitch accuracy and 2.542 cents MAE, with 102 final warnings across 52 units (5.044\%). Its technique similarity is 0.6323 and ornament F1 is 9.492, below both trained students. Its tone-type distribution similarity is higher, however (Appendix~\ref{sec:detailed-results}). These measures capture different aspects of realization; the cross-model comparison alone does not establish that trajectory training is necessary for idiomatic playing.

\subsection{Ablation Studies}\label{sec:ablations}

\paragraph{Pitch correctness and diagnostic feedback.}
The full system attains 99.981\% pitch accuracy on 15,758 evaluable events, compared with 86.237\% on 15,360 events when diagnostic feedback is disabled (Table~\ref{tab:main-results}). MAE is 2.308 versus 64.993 cents. Since the evaluable sets differ, Table~\ref{tab:warning-ablation} additionally reports accuracy on 14,289 events resolved in both conditions: 99.979\% versus 86.941\%, a gap of 13.038 percentage points. The observed accuracy gap therefore persists on the same input events. The result concerns auditor-supported realizations and does not establish accuracy on unresolved notation.

\paragraph{Residual warnings and error analysis.}
The full system leaves two final runtime warnings in two work units, compared with 3,436 warnings across 809 work units for OFF. The affected-work-unit rate is 0.194\% versus 78.468\%. One remaining ON warning in \emph{Youlan} is an octave error, realizing E6 for a target E7. These cases warrant inspection of inherited state, compound notation, and ordinary pitch choices. Final-warning counts and pitch-error counts use different eligibility and matching rules and should not be treated as interchangeable metrics.

\paragraph{Fingering agreement and idiomatic realization.}
The full system's string, left-hand, right-hand, and tone-type F1 scores are 39.761, 57.119, 46.009, and 62.543, respectively. Their modest differences from OFF accompany a much larger pitch-accuracy gap. The full system also has lower ornament F1: 20.184 versus 22.285. The current comparison provides evidence of improved pitch consistency without establishing an advantage in ornament selection.

Tone distributions indicate that pitch accuracy leaves room for different realization strategies. Among recognized tone types on reference-labeled events, harmonics account for 7.51\% of ON predictions, compared with 29.34\% of reference tone types. A system can realize the correct pitch through different strings, positions, or tone types, and can also underuse stylistically appropriate techniques. Both possibilities motivate examining action distributions and consulting performers when assessing idiomatic quality.

\paragraph{Single-stage versus two-stage planning.}
The single-stage student completes all 1,031 work units, with 98.732\% pitch accuracy on 15,935 evaluable events and 7.880 cents MAE. On their 14,580 common evaluable events, accuracy is 98.807\% for single-stage and 99.979\% for two-stage, a gap of approximately 1.173 percentage points. \paragraph{Teacher trajectory construction.}
We compare the standard single-stage student with a student trained on fixed-workflow trajectories. Each fixed trajectory contains generic reasoning, one real pitch-candidate query, and one edit constructed from the expert annotation, without a teacher API rollout. Both students are evaluated with diagnostic feedback and a 16-round stage limit on the same 48 scores using complete generated histories. This comparison keeps the architecture single-stage; training trajectories and some system/user prompts differ, so it evaluates the construction recipes rather than an isolated causal effect of interactive teacher reasoning.

The fixed-workflow student achieves 100\% protocol-valid coverage, but pitch accuracy is 26.778\% on 13,556 evaluable events and MAE is 517.624 cents. The standard single-stage student attains 98.732\% on 15,935 events and 7.880 cents MAE. On their 12,792 common evaluable events, accuracy is 26.931\% versus 98.781\% (Table~\ref{tab:trajectory-ablation}). Thus, the large pitch gap persists on a shared event set rather than arising solely from different parseability.

\subsection{Expert Evaluation}
A blinded performer study will complement automatic metrics. Proposed dimensions are physical execution feasibility, conformity to playing conventions and continuity of hand movements, and expressive suitability or \emph{yunwei}. The last dimension concerns how slides, vibrato, and compound gestures serve the musical phrase; it is not defined by ornament count or reference F1. Examples will be anonymized and presented in randomized order, with input scores available to raters. The study will report rater experience, sampling, agreement between raters, and uncertainty of the estimates. Expert scores and claims of superior playability or expression await this assessment.
